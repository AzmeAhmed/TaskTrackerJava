# TaskTrackerJava
A lightweight console-based task management application built in Java. This project demonstrates core Java fundamentals, dynamic array handling, robust input validation, and file I/O operations.

## Features
- **View Tasks:** Lists all current tasks with 1-based indexing for user clarity.
- **Add Tasks:** Dynamically appends new tasks using ArrayList.
- **Remove Tasks:** Safely deletes tasks by index position.
- **Error Handling:** Protects against NumberFormatException when processing numerical user inputs.
- **Persistent Storage:** Saves tasks to a local .txt file upon exiting.

## Tech Stack
- **Language:** Java 17+
- **IDE:** IntelliJ IDEA
- **Core Concepts:** Scanner, ArrayList, while loops, try-catch blocks, FileWriter

## How to Run
1. Open the project in IntelliJ IDEA.
2. Run the `Main.java` file.
3. Follow the on-screen console instructions to manage your tasks.
